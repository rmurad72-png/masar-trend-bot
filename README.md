# مسار — بوت متابعة الاتجاه على OKX

بوت Python يطبّق نظام اختراق قناة دونشيان على الإطار اليومي، ويُدار بالكامل من تيليجرام.
مستند التصميم الكامل: «تصميم بوت متابعة الاتجاه — تداول ورقي على OKX».

## القواعد (مطابقة للباك تست)

| البند | القاعدة |
|---|---|
| الدخول | إغلاق يومي (UTC) فوق أعلى قمة 55 يوماً → شراء عند الافتتاح التالي |
| فلتر BTC | لا شراء لعملة غير BTC إلا إذا كان BTC في اتجاه صاعد (اختراق 55 يوماً ولم يكسر قاع 20 يوماً بعدها) |
| البيع | BTC وETH فقط: إغلاق تحت أدنى قاع 55 يوماً، عقود دائمة بهامش معزول ورافعة 3x |
| الوقف الأولي | 2 × ATR(20) يومي، أمر شرطي على المنصة فور الدخول |
| الخروج | إغلاق تحت قاع 10 أيام (للشراء) أو فوق قمة 10 أيام (للبيع) |
| إعادة الدخول | فقط مع اختراق جديد |
| المخاطرة | 0.5% للصفقة، سقف 5% للمخاطرة المفتوحة |
| الحماية | إيقاف الصفقات الجديدة عند تراجع 20% من القمة حتى `/resume` |

الأصول (22، بترتيب الأولوية): BTC ETH SOL BNB XRP DOGE AVAX LINK BCH LTC ADA HBAR INJ SEI SUI CFX XLM SHIB XTZ APT ALGO TRX

**الباك تست** (يوليو 2020 – نوفمبر 2026، نفس الإعدادات): 273 صفقة، متوسط +1.24R، عامل ربح 2.96.
بمخاطرة 0.5%: حوالي 21.6% سنوياً وتراجع أقصى 16%. الأرقام متفائلة؛ آخر سنتين كانتا شبه مسطحتين.

## الحسابات

- **المحفظة الافتراضية** (`paper`): تعمل افتراضياً بـ 10,000$، تنفّذ بأسعار OKX الحية مع انزلاق 0.05% وعمولة، وتفحص الوقف على شموع الساعة.
- **الحساب الحقيقي** (`live`): حساب فرعي على OKX. لا يعمل إلا بعد إضافة المفاتيح و`LIVE_ENABLED=true`. البيع فيه مغلق حتى `LIVE_SHORTS=true`.

## التشغيل من الجوال

1. **تيليجرام:** أنشئ بوتاً عبر @BotFather وخذ التوكن، واعرف رقم محادثتك عبر @userinfobot.
2. **Supabase:** مشروع جديد → Connect → Transaction pooler → انسخ رابط الاتصال (يبدأ بـ `postgresql://`).
3. **Railway:** New Project → Deploy from GitHub → هذا المستودع → Variables، وأضف:
   `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `DATABASE_URL`. انظر `.env.example`.
4. سيصلك «🚀 بوت مسار يعمل»، ثم يعمل البوت يومياً 03:00 بتوقيت الرياض.

### لاحقاً: الحساب الحقيقي

1. في OKX أنشئ حساباً فرعياً وحوّل له المبلغ.
2. أنشئ مفتاح API للحساب الفرعي بصلاحية **Read + Trade فقط** — لا تفعّل Withdraw أبداً.
3. للبيع على BTC/ETH يجب أن يسمح وضع الحساب بالعقود (Spot and futures mode).
4. أضف `OKX_API_KEY`, `OKX_API_SECRET`, `OKX_API_PASSPHRASE`, ثم `LIVE_ENABLED=true`.

## أوامر تيليجرام

| الأمر | الوظيفة |
|---|---|
| /status | الرصيد، المراكز وربحها بـ R، المخاطرة المفتوحة، التراجع |
| /positions | الدخول والوقف ومستوى الخروج لكل مركز |
| /watch | الأقرب للاختراق واتجاه BTC |
| /report | ملخص الأداء مقابل الباك تست |
| /pause · /resume | إيقاف/استئناف الصفقات الجديدة |
| /close_all | إغلاق كل شيء (بزر تأكيد) |
| /run_now | تشغيل الدورة اليومية الآن إن لم تُنفّذ اليوم |

## الأمان

- الوقف أمر مسجّل على OKX، فتبقى الصفقة محمية حتى لو توقف البوت. إذا فشل تسجيل الوقف تُغلق الصفقة فوراً.
- كل أمر يحمل `clOrdId` ثابتاً (الحساب + النوع + التاريخ + الأصل)، فلا يتكرر عند إعادة المحاولة.
- مطابقة يومية بين المراكز في قاعدة البيانات والحساب الفعلي؛ أي اختلاف يوقف الصفقات الجديدة ويرسل تنبيهاً.
- البوت يرد على رقم محادثتك فقط.

## التحقق (المرحلة 0)

```
pip install -r requirements-dev.txt
python -m pytest -q
python tools/parity.py <مجلد ملفات الساعة CSV> [ticks.json]
```

`tools/parity.py` يشغّل محرك الباك تست الأصلي (`tools/reference_backtest.py`) ويعيد تشغيل دوال البوت يوماً بيوم على نفس الشموع.
النتيجة على بيانات 2020–2026: **الدخول 273/273، الخروج بالقناة 119/119، ولا إشارات زائدة.**
